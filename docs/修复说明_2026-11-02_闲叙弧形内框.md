# 闲叙青釉、闲叙邂逅弧形内框

本文记录青釉、邂逅阶段。用户随后增加了浅川、素年的修复要求，见 `修复说明_2026-11-02_闲叙浅川素年内框.md`；下文“不修改浅川”描述的是该阶段范围。

按用户提供的浅川、邂逅成品参考，中央色块边界随目标轮廓形成弧形，内部纹理保持统一比例，外围背景纹理连续铺排。浅川只作形式参考，本次不修改浅川或其他花型的处理规则。

原先两侧平滑收拢的采样会挤压边缘纹理；现在仅在青釉、邂逅的纹理内框上启用统一等比采样，由弧形边界裁取。范围之外的纹理允许自然裁去，不强行把整幅长条纹理挤入内框。哥特玫瑰等描边画框和牡丹织锦的原处理不变。

对两端为半圆或接近半圆的弧形台，原通用内缩上限会降到零或过小，导致中央色块覆盖浅色外层。本次仅在这两款纹理内框中按同心平行弧重新计算有效内框，不修改通用几何逻辑。新增两款花型、两种直边长度共四个回归场景；180×80cm、直边 100cm 的邂逅示例已恢复外围斜纹。

另外，一些素材单侧留白小于完整背景周期，原识别会放弃中央内框。现允许从四侧实际背景按周期相位取得完整纹理，检查四侧相位一致后使用，保持外围斜纹的原比例。周期或像素覆盖无法得到验证时，保留原识别结果；不拉伸外围纹理，不凭空填补缺失部分。这不是对所有名含“闲叙”的图片强制套用弧形模板。

验证覆盖：

- 全量 601 项测试通过；最后追加复验的 34 项闲叙内框、哥特画框定向测试通过。
- 像素对照回归：中央及两侧统一比例；内外纹理沿弧形分界；四侧取得的背景周期不混入中央色块或黑边。
- 普通画框、闲叙浅川、闲叙素年保持原排版，哥特玫瑰定向测试通过。
- 十份矩形实物素材：青釉 85×140cm；邂逅 90×180、48×200、35×218、35.5×440、30×100、35×140、35×180、38×100、40×150cm。预览全覆盖，青釉 85×140、邂逅 90×180 与 48×200cm 另检查原图精度；两种轮廓、两组目标尺寸共 52 次渲染检查通过。
- 牡丹织锦、克罗印花、青芜织序、塞纳时光、堇色素颜五份实际素材对照输出与修改前逐像素一致。验证结果仅代表这些样本和场景，未遍历全部图库。

已知限制：本地 45×310cm 邂逅素材尚不能从四侧验证完整背景周期，仍保留原处理，未计入上述通过场景；本次未强行重建其背景。
