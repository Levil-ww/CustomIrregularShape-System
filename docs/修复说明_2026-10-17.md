# 圆弧边框修复说明（2026-10-17）

## 修复内容

| 问题 | 原因 | 修复后的行为 |
| --- | --- | --- |
| 玫瑰骑士转角下方有细横线或浅色接缝 | 旧矩形描边带小数坐标，清理范围漏掉相邻像素的采样边缘，淡化反算放大 JPEG 压缩误差 | 清理范围增加一个源像素，覆盖采样边缘，保持花纹位置和淡化留边 |
| 悠米提示“干净花纹区不足”，不能生成 | 中央纯色缺少后续内容转折，扫描器丢弃了已经确认的周期边框 | 保留靠近外缘且后续区域平整的浅层周期边框；仍拒绝真正无法覆盖目标的素材 |
| 欧克内侧浅线未随外框变化 | 仅外侧黑线被识别为边框，多层浅线遗留在普通矩形内容区 | 验证浅色线四边闭合、中央及周围底色稳定后，把整组线框随目标轮廓绘制 |

欧克的处理按图像结构启用，不依赖花名。未闭合线框、明显中央图案等不满足条件的素材保留既有分析流程。外侧存在周期装饰时保留完整条带；仅切向颜色均匀的连续线框采用径向色彩条带。预览与原分辨率分别验证，允许旧外框边缘的少量 JPEG 和取整误差。

## 使用说明

1. 更新源码后关闭并重启应用，重新匹配素材、生成预览并导出。
2. 已有成品图不会自动更新，需要重新生成。
3. 本次提交只更新源码、回归测试与说明，没有重新打包 EXE；使用旧 EXE 无法获得这些修复。
4. 本次没有调整订单尺寸、补偿规则、自动匹配规则或模型全局尺寸校验，没有新增依赖。
