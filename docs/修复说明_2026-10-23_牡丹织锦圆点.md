# 牡丹织锦圆点完整性修复

原边框提取要求一行中超过 95% 的像素属于边框，圆点向内收窄的末端不满足条件，因此被提前截掉。实际 80×131cm 素材在 134×81cm 弧形台订单中出现底边圆点缺失。

修复后按装饰实际像素延伸范围提取完整边框，并保留一行识别余量供原分辨率重采样。上下左右共用相同规则；牡丹织锦各尺寸使用同一套结构识别和排版流程，尺寸只影响缩放及适配参数，不增加具体尺寸特例。中央花纹继续保持比例并在两侧平滑随弧变化，保留原留白和边框层次。

验证结果：

- 新增两种分辨率下四侧圆点末端完整性回归测试；593 项全量测试通过。
- 实际素材 40×60、60×70、80×80、80×130、80×131、82×160cm，在预览/原图精度、圆桌/弧形台和三组目标尺寸下共完成 72 次渲染检查，并检查四侧装饰末端均在提取范围内。
- 六份素材用于覆盖不同尺寸，未声称已遍历图库全部牡丹织锦文件；所有尺寸均使用本次修复的共用逻辑。

本次提交包含源码、回归测试和说明，未重新打包 EXE。现有 0.4.2 分发程序需要重新构建后才包含本修复，也可直接运行更新后的源码。关闭旧程序后重新启动、匹配素材、生成及导出；已有成品不会自动更新。
