# 异形智裁 用户使用说明

## 一、软件简介

异形智裁是一款专业的素材裁剪工具，支持将矩形 JPG 素材智能排版到圆桌和弧形台轮廓中，保留原图花纹层次和边框，导出高清成品图。

**核心特点：**
- 本地处理，无需联网
- 自动识别素材花纹和边框
- 支持草图上传 + OCR 尺寸识别
- 预览/打印双分辨率输出

---

## 二、安装与启动

### 系统要求
- Windows 10/11 64 位
- 无需安装 Python 或第三方运行库；草图识别需系统有可用的 Windows OCR 语言，优先英语，否则可手工填写尺寸

### 启动方式
先将分发 ZIP 完整解压到本地文件夹，再双击 `异形智裁.exe`。每次启动单文件程序时可能需要几秒解压时间。图库素材需自行准备并选择目录。

## 四、操作步骤

### 方式一：手动输入尺寸（推荐新手）

**第 1 步：选择轮廓类型**
- 点击顶部 Tab 选择「圆桌/弧形台」

**第 2 步：输入目标文件名**
- 在「目标文件名」输入框中输入或粘贴文件名
- 示例：`双面格-定制-裁剪有图-花幔;80X140cm 裁剪...`
- 程序会自动解析尺寸（80×140cm）

**第 3 步：核对尺寸**
- W 最大宽度 cm：自动填充（可手动修改）
- H 总高 cm：自动填充（可手动修改）
- L 直边 cm（弧形台专用）：手工填写，或上传草图识别后核对；不能仅凭宽高推算

**第 4 步：选择素材图库**
- 点击「选择」按钮，选择包含矩形 JPG 素材的文件夹
- 程序会自动匹配最合适的素材

**第 5 步：预览与生成**
- 点击「匹配并预览」查看效果
- 满意后点击「生成成品」导出高清图

---

### 方式二：上传草图识别尺寸（推荐有草图的用户）

**第 1 步：准备草图**
- 草图需包含尺寸标注（如 86×138cm）
- 支持 JPG/PNG 格式

**第 2 步：上传草图**
- 点击「上传草图并识别尺寸」按钮
- 选择草图文件

**第 3 步：核对识别结果**
- 程序会自动识别草图中的尺寸数字
- 检查识别结果是否正确，如有误差可手动修正
- 勾选「已对照草图核对模块及尺寸」

**第 4 步：继续后续步骤**
- 选择素材图库 → 预览 → 生成成品

## 五、尺寸说明

### 圆桌尺寸
- **W 最大宽度**：圆桌直径（含补偿）
- **H 总高**：截圆后的总高，可小于或等于 W；H 等于 W 时为完整圆

### 弧形台尺寸
- **W 最大宽度**：弧形台最宽处
- **H 总高**：弧形台总高度
- **L 直边**：上下水平直边长度（不补偿），以草图实际标注为准

### 尺寸补偿
- 程序默认宽、高各补偿 1cm（用于包边）
- 弧形台直边保持草图值，不补偿

## 六、输出说明

### 预览图
- 最长边 1200px
- 用于快速查看效果
- 用时受素材、目录、硬件与轮廓影响，以界面实际计时为准

### 打印图
- 按目标厘米尺寸与 DPI 计算像素尺寸，默认 150 DPI；全尺寸导出从原素材采样
- 用于实际打印输出
- 生成时间较长（视尺寸而定）

### 输出格式
- JPG：适合打印，文件较小
- PNG：保留轮廓外透明区域；JPG 使用白底

## 七、常见问题

### Q1：为什么识别的尺寸不对？
A：OCR 识别可能受草图清晰度影响。建议：
- 使用清晰的草图照片
- 手动修正识别结果
- 直接手动输入尺寸

### Q2：提示"素材尺寸偏小"怎么办？
A：素材尺寸小于目标尺寸的 80%，放大后可能模糊。建议：
- 更换更高分辨率的素材
- 或接受当前效果（小尺寸订单影响不大）

### Q3：什么时候需要重启程序？
A：更换新版 EXE 后需要重启，普通生成后无需重启。更新后重新匹配、预览和导出；已有成品不会自动更新。

### Q4：支持哪些花型？
A：程序按图像特征自动识别，不依赖花型名称。已验证的花型包括：
- 哥特玫瑰、青芜织序、繁花说、里芙、花幔
- 大理石系列、戴安娜、安妮森林等 30+ 种

### Q5：如何保存项目？
A：使用「手工排版」功能可以保存 JSON 项目文件，下次打开继续编辑。

## 八、注意事项

1. **更新后必须重启程序**，并重新匹配、生成和导出
2. **图库素材尺寸与订单比例不同**时会有提示，请核对
3. **程序本地处理**，不会上传任何数据
4. **首次启动**可能需要几秒解压时间
5. **生成大图时**请耐心等待，不要关闭程序
