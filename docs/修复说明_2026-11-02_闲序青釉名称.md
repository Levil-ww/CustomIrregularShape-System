# 闲序青釉名称及弧形内框

“闲序青釉”“闲序·青釉”“闲叙青釉”“闲叙·青釉”是同一花型。文件名解析统一映射为闲叙青釉，以便订单、图库素材和排版使用同一处理流程；保留原始文件名及尺寸，不改变其他花型名称。

截图所用 85×137cm 素材此前还未识别出中央内框。现有周期识别失败时，仅针对青釉检查中央深色纹理和四周浅色背景；通过结构验证后，中央纹理等比铺入弧形内框。背景优先使用经验证的原纹理周期；无法取得完整周期时连续适配原始四侧背景，不补造背景。

649 项全量测试通过。验证覆盖四种名称的订单及素材双向匹配，保留原始订单名称与 85×133cm 尺寸；检查两种轮廓下中央区域随弧形变化，并检查其他“闲序”名称未被误改。截图所用 85×137cm 原素材的五种名称在预览和原图精度、圆桌和弧形台下共完成 20 次渲染，结果逐像素一致。另检查 8 个实际素材（30×40cm 至 33×350cm），每个素材以原尺寸及其 90%、110% 尺寸生成弧形预览；并针对狭长比例补充识别测试，移除内框宽度的固定上限，保留四周留白与纹理验证。七款既有素材的对照输出与修改前逐像素一致。未列出的所有素材与尺寸不能视为已经逐一验证。

本次仅更新源码，现有 0.4.3 EXE 不包含此修复；需使用更新源码或重新构建程序，关闭旧进程后重新启动并重新匹配、生成和导出，旧成品不会自动更新。
