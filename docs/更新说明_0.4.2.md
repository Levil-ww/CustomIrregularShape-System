# 异形智裁 0.4.2 更新说明

构建日期：2026-10-21；交付核验日期：2026-10-22。适用于 Windows 10/11 64 位。

## 本次打包范围

使用当前业务源码 `841157a`，将窗口版本更新为 0.4.2 后重新构建。包含 0.4.1 原有功能及以下后续修复：

- 青芜织序：按素材的闭合内线和周期装饰结构提取完整多层边框，避免宽黑色外沿截断扫描；中央花纹独立等比填充。
- 塞纳时光：清理混入内容区的旧矩形边框像素，避免图案缩小后出现多余横线，保留中央图案和正常轮廓边框。
- 克罗印花：验证四侧层数、直线段和圆角连通性后补全遗漏的第二道闭合内线，两道线及线间留白随轮廓保留；断线保护继续生效。

这些修复此前仅包含在源码中，10 月 19 日生成的 0.4.1 EXE 不包含它们。

## 交付和升级

普通用户只需接收 `异形智裁.exe`，无需安装 Python 或另外复制 Qt、DLL、图标及 OCR 脚本。ZIP 是包含手册和校验清单的配套交付方式。

1. 关闭旧程序，使用新版 EXE 替换原 EXE，检查快捷方式指向。
2. 启动后确认窗口标题为 0.4.2。
3. 重新匹配素材、生成预览并导出；已有成品不会自动更新。

原图库、历史成品、JSON 项目和当前 Windows 用户的目录设置无需迁移。草图 OCR 仍依赖系统可用的识别语言，不可用时可手工输入尺寸。

## 验证和文件清单

分发包中的 `构建验证.txt` 记录本轮测试和启动检查；`发布清单.json`、`SHA256SUMS.txt` 记录源文件摘要和交付文件校验值。冻结的业务模块会与本轮源码编译结果核对，避免遗漏最新修复。

构建日志和测试临时文件保留在本地 artifacts；EXE、ZIP 和发布清单位于本地 dist，不随 Git 推送。独立正圆/同心圆标签、马肚形及跑道形椭圆仍待开发。
