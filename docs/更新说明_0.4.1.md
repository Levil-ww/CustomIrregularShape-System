# 异形智裁 0.4.1 更新说明

发布日期：2026-10-19。适用于 Windows 10/11 64 位。

## 打包范围与重要说明

- 本次已有分发包基于 `29c593c` 对应的业务源码构建，并使用 0.4.1 版本标识。之后提交的 `6129a77`“青芜织序按素材结构识别多层边框”修复尚未包含在这个 EXE 中；需要该修复时，应从最新源码重新打包并验证。
- 普通用户可以只接收一个 `异形智裁.exe`，无需额外复制 DLL、Python、图标或 OCR 脚本；配套手册和更新说明可按需提供。
- `build/`、`dist/` 为本地生成目录，不随 Git 提交或推送。源码仓库中的打包配置和文档已同步，现有 EXE、ZIP 和校验清单保留在本地 `dist/`。

## 本次更新

本版重新打包上述构建时点的源码，替换 2026-10-10 的旧 EXE，包含此前 0.4.0 功能和以下 10 月 17 日、19 日的修复：

- 花型名称统一忽略装饰中点和空格，标准款优先读取分号后的订单尺寸，保留原输出文件名，图库无需改名。
- 牡丹织锦、素缕花肆及已验证内框的闲叙青釉、邂逅，中央花纹保持比例，两侧平滑随弧；清除闲叙内框的背景余边。
- 保留实心圆点边框在圆桌和弧形台转角处的完整性。
- 修复欧克多层内线仍为矩形、悠米边框漏识别及玫瑰骑士转角细横线。
- 用户手册同步修正功能范围、圆桌总高、弧形台直边输入和输出分辨率说明。

## 如何升级

1. 关闭正在运行的旧版程序。
2. 完整解压本次 ZIP；使用新版 `异形智裁.exe` 替换旧程序，删除旧快捷方式或确认其仍指向新程序。
3. 同步本包的 PDF 用户手册、Markdown 使用说明和本更新说明，避免继续参考旧文档。
4. 启动后确认窗口标题为 0.4.1，重新匹配、生成预览并导出。旧成品不会自动更新。

## 哪些文件需要同步

- 必须更新：`异形智裁.exe`。
- 配套更新：用户手册 PDF、用户使用说明.md、更新说明_0.4.1.md。
- 已内置：Python 运行环境、Qt/NumPy/Pillow、应用图标、Windows OCR 调用脚本；无需单独复制。
- 无需迁移：原图库、历史成品、JSON 项目和原 Windows 用户的目录设置。图库素材不随安装包提供。
- 校验文件：`SHA256SUMS.txt` 与 `发布清单.json`，用于核对包内文件和构建环境。

OCR 仍依赖系统可用的 Windows OCR 语言；无法识别时可手工输入。独立正圆/同心圆标签、马肚形和跑道形椭圆仍待开发。
