# 异形智裁 0.4.3 更新说明

本次重新构建日期：2026-11-12。适用于 Windows 10/11 64 位。2026-11-02 曾发布过同为 0.4.3 的旧 EXE；窗口版本号相同，应以构建日期或发布清单中的 SHA-256 区分。

## 本版更新

11 月 12 日重打包包含此前 0.4.3 及之后的源码更新：

- 花幔：在已验证闭合细线且扫描越界时重新提取边框，避免花枝碎线混入；验证覆盖三份素材。
- 佩斯：修复弧形台直边中央条纹被误清除的问题，保留四角空隙。
- 岁月珐琅：对已验证完整背景周期的素材保留绿色装饰并适配弧形内框。30×120cm、80×140cm 和 60×100cm 素材的相关内框问题仍未完成修复。
- 将“闲序青釉/邂逅”与对应“闲叙”名称统一匹配；青釉在结构验证通过时兼容更多尺寸。
- 自动匹配仅考虑长、短边均达到目标相应尺寸 80% 的同材质、同花型素材；没有合格素材时提示补充素材或手动指定。

以下为 11 月 2 日旧版已包含的更新：

- 修复牡丹织锦圆点边框末端被裁剪，保留稀疏圆点及重采样余量。
- 闲叙青釉、邂逅的中央色块随内侧弧形轮廓显示，内部纹理保持统一比例，外围背景按已验证周期铺排。
- 闲叙浅川、素年在四侧闭合细线得到验证后，中央纹理和细线适配弧形内框；保留素年沿框圆点及末端，兼容常见分隔点写法。
- 对单侧留白不足的素材，从四侧已验证背景提取并校验完整周期；无法验证时保留原处理。

以上更新在旧版 0.4.2 EXE 中不可用。本地 45×310cm 闲叙邂逅素材尚不能验证完整背景周期，仍保留原处理；实际验证仅覆盖记录中的素材和尺寸。

## 升级方法

用户可以只接收 `异形智裁.exe`，无需安装 Python 或另外复制 Qt、图标和 OCR 脚本。关闭旧程序，替换 EXE 后启动，确认窗口显示 0.4.3，再重新匹配、预览和导出。旧成品不会自动更新；原图库、JSON 项目和目录设置无需迁移。

草图 OCR 依赖 Windows 系统可用的识别语言，不可用时可手工输入。独立正圆/同心圆标签、马肚形和跑道形椭圆仍待开发。

ZIP 可选，内含使用说明、更新说明及校验清单。`build/` 和 `dist/` 为本地生成目录，不随 Git 推送。验证范围与已知限制详见仓库内 2026-11-02 两份闲叙修复说明和 2026-10-23 牡丹织锦修复说明。
