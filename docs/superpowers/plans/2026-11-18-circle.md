# 正圆与同心圆 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** 实现正圆与同心圆的图库匹配、预览和导出界面。

**Architecture:** 独立圆形服务负责解析、候选匹配和素材读取，纯计算模块负责圆形合成；独立 GUI 模块通过后台线程调用服务，复用现有导出和预览组件。

**Tech Stack:** Python、PyQt5、Pillow、pytest；不新增依赖。

**Spec:** docs/superpowers/specs/2026-11-18-circle-design.md

## Global Constraints

保持分层、原有用户修改和已有校验；尺寸以厘米表达，像素转换发生在渲染时。

## Review Focus

文件名无尺寸、手工覆盖、尺寸不合法、圆形素材缺失、输出尺寸与间隙的准确性。

### Task 1: 解析、匹配和合成

- [ ] 增加圆形文件名解析与候选匹配，覆盖大小写、直径和候选优先级。
- [ ] 增加正圆和同心圆纯合成，覆盖间隙、线宽和尺寸校验。
- [ ] 增加服务层预览与 DPI 导出，并运行对应测试。

### Task 2: 用户界面

- [ ] 替换占位页，提供尺寸、素材、预览与导出控件及后台线程。
- [ ] 验证自动识别与手动优先、异常提示和现有 GUI 测试。
- [ ] 运行相关测试及完整测试，记录真实素材验证范围。
