# 圆桌 / 弧形台素材设计器 0.3.0

独立 Python / PyQt5 桌面程序，支持目标文件名匹配、精确截圆、完整圆及同心内圆填充。保持 models / core / services / workers / gui 分层，不依赖 SmartShapeCrop 运行。

## 弧形台与草图识别

在统一“裁剪”Tab 中选择圆桌或弧形台。圆桌输入最大宽度（直径）和总高；弧形台额外输入上下直边长度，采用上下、左右对称的短圆弧模型。宽、高默认各增加 1cm，**直边不补偿**：文件名 `花幔;86x138cm`，草图直边108cm，输出最大宽度139cm、总高87cm、直边108cm。输出仍保留原文件名。

可上传 PNG/JPG/BMP/TIFF 草图，后台使用 Windows 自带 OCR，本地识别，不上传图片、不下载模型。红色标注优先分离识别，再识别原图；结合标注位置关联最大宽度、总高、直边，并处理被 OCR 分开的数字和小数点。只有两处尺寸时给出长边/总高候选，不猜测弧形台直边。

上传后显示原草图、可编辑参数、实际输出轮廓和识别报告。对照草图核对模块及尺寸后勾选确认，再预览或导出。尺寸与文件名不同时显示提示，按当前字段生成；修改尺寸后需重新核对。更换目标名会清除前一个订单的草图及直边。OCR 无法可靠关联、语言不可用或平台不支持时，可手工输入；Windows 需有可用的系统 OCR 语言（优先英语，回退用户语言）。首版不支持任意曲线、非对称轮廓及自动描边拟合。

手工排版中的尺寸为实际输出尺寸，不再次补偿，支持两种轮廓及 JSON 保存/读取。

## 启动

```powershell
python -m pip install -r requirements.txt
python main.py
```

当前工作环境运行依赖已可用。

## 默认工作流

1. 输入目标名称，例如 `双面格-定制-裁剪有图-花幔;80X140cm裁剪有图`。
2. 选择矩形 JPG 素材图库（递归扫描）和输出目录。目录选择会记住。
3. 点击“自动匹配并预览”，核对匹配结果与效果。
4. 点击“生成成品”。默认 JPG 白底，也可选透明 PNG。成品名称保持输入名称，扩展名按所选格式。

示例生成外圆直径 **141cm**、保留总高 **81cm**：文件名长边、短边各加 **1cm 总尺寸补偿**，不是每边加 1cm，导出不再次补偿。

匹配先限定同材质、同花型，再按比例差排序，比例相同时按尺寸差排序。横竖统一按长边×短边比较。候选仅为矩形 JPG/JPEG；带“裁剪有图、圆形、直径、水池、挖角”的素材会被排除。没有同花型素材时报告失败，不自动替换其他花型。

## 性能与界面

界面采用可拖动分栏：左侧编辑订单、尺寸和目录，右侧显示成品、轮廓及匹配来源；主要操作按钮固定在左侧底部。文件名输入框按 Enter 即可匹配并预览。更换订单会提示重新预览，导出进度在编码和保存完成后才到 100%。

首次匹配建立花型索引。Windows 桌面版用单个递归目录通知监听图库（支持 SMB 共享），之后换订单直接查询内存索引，**不再遍历网络目录**。增加、删除、改名按通知增量更新，新增子目录只扫描新目录；通知溢出或共享盘监听失效时回退核对目录。高级场景可点击“刷新图库索引”强制核对；命令行默认每次核对目录。索引保留最近使用的 4 个图库，仅在本次运行内复用；首次使用或重新打开程序仍需扫描一次。

素材读取与完整边框分析使用最多 256MiB、8 项的内存缓存。大图预览先用 JPEG 解码器缩小读取，再以最长边 2400px 分析和渲染（显示预览最长边 1200px）；导出独立读取原分辨率素材，不使用预览缩图。小素材可共享预览与导出缓存。原图通过 EXIF 原位调整、跳过重复 RGB 转换和内容区视图减少大图副本；素材文件修改或替换后自动重读。像素采样采用 float32 减少临时内存，插值舍入与旧版的通道差在测试中不超过 1/255。PNG 使用快速无损压缩，透明度和像素不变，文件可能稍大；JPG 仍使用质量 95 和无色度降采样。

运行 `python benchmarks/performance.py` 可复测匹配、素材准备、渲染和编码耗时；时间取决于图库大小、DPI、磁盘和图片内容。运行 `python benchmarks/gui_preview.py` 可离屏生成界面检查图（Windows）。

连续不同订单可用 `python benchmarks/order_switch.py` 测量；真实共享图库可用 `python benchmarks/catalog_probe.py "图库路径" --session` 只读测量桌面监听模式，去掉 `--session` 可对比逐次目录核对。预览完成后状态栏显示匹配与预览的实际耗时。

## 原素材排版

- 自动读取最外缘到中央花纹的完整边框带，包括外线、留边底色、色带、圆点装饰和内层分隔线。
- 自动模式直接采样原颜色和线条，不叠加首版固定描边，不用手工花边选区截断圆点。
- 四边分别识别内容边界，中央花纹保持原方向、布局和颜色。以目标直径确定整幅素材的统一等比缩放，再按目标高度从中心上下等距裁剪；不镜像、复制、平铺或单独放大花纹。花纹内部的空白行不再被误判为边框。
- 上下对称仅用于边框的周长映射。自动取能覆盖原四边的统一边宽，各层共同等比调整，避免原矩形竖边露出；边框宽于目标高度时明确提示，避免自动补画而改变原图。
- 各层厚度按统一比例换算成厘米，再沿截圆等距轮廓重排；装饰图案按原物理比例沿周长映射。
- 自动检测针对有清晰横向分隔线的矩形产品图。界面显示识别深度；没有可靠边界时明确提示并保留原图填充，可转手工工具。

装饰条带先排除原矩形转角，再自动提取完整花纹周期，以整数周期闭合新周长；沿周向允许小幅缩放以消除任意尺寸下的起止相位跳变，径向各层宽度保持统一比例。无法可靠检测周期的非重复图案仍使用完整安全条带，可能有图案接缝。自动模式没有使用生成式重绘或修改素材色彩。

## 高级选项

默认折叠：总尺寸补偿（1cm）、DPI（150）、同心内圆外径（0 关闭）、指定素材（跳过匹配）。自动模式通常不需框选素材、设置花边宽度或选择颜色。

“手工排版工具”保留首版尺寸、边框、选区、JSON 设计保存能力。同心内圆使用原素材边框与同样的花纹缩放，当前为填充圆，不是真实镂空。

## 几何与输出

轮廓为 `x²+y² ≤ (D/2)²` 与 `|y| ≤ H/2` 的交集。上下直边长 `sqrt(D²-H²)`。`H=D` 时为完整圆。内缩 t 后半径为 `D/2-t`、水平半高为 `H/2-t`。

输出写入 DPI 元数据。预览最长边 1200px；全尺寸分块处理，但最终画布仍驻留内存，限制为 1.8 亿像素。

## 命令行与测试

```powershell
python -m shape_crop.cli --target "双面格-定制-裁剪有图-花幔;80X140cm裁剪有图" --library "素材图库" --output-dir "输出目录"
python -m shape_crop.cli --config "圆桌设计.json" --output "成品.png"
python -m shape_crop.cli --target "花幔;86x138cm" --shape arc --straight 108 --material "素材.jpg" --output-dir "输出目录"
python -m pytest tests -q
```

[架构说明](docs/ARCHITECTURE.md)记录各模块维护入口。旧 JSON 可继续读取，素材默认升级为自动排版；手工窗口生成时明确使用 manual 模式。

暂未接入 PSD、色彩配置转换、持久化图库索引或非周期图案接缝优化。
